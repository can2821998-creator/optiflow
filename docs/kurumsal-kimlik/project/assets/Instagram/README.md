Instagram için hazır PNG'ler. Kare gönderiler 1080 × 1080: `bilgi.png`, `ozellik.png`, `koken.png`, `muayene.png`. Hikâye 1080 × 1920: `story.png`. Profil fotoğrafı `profil.png`; öne çıkan kapakları `kapak-sgk.png`, `kapak-atolye.png`, `kapak-fiyat.png`, `kapak-rehber.png`, `kapak-demo.png`. Örnek metinler değiştirilecekse kaynak şablonlar depoda `docs/kurumsal-kimlik/sablonlar/`.
